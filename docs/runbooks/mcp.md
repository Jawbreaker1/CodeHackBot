# MCP tools

BirdHackBot workers can use locally configured MCP servers over stdio. This is optional: no server is launched unless a worker proposes an MCP action and the session's approval policy permits it. The coordinator remains responsible for planning; workers discover advertised tools, inspect one tool schema, and call the relevant tool. Calls use the same action review, execution log, context offload, and evidence path as shell and browser work.

Copy `config/mcp-servers.example.json` to `config/mcp-servers.local.json` and replace the example entry with an installed, trusted MCP server command. Use an absolute executable path and literal arguments. The local file is ignored by Git. A worker's `mcp_list` action starts that server in its task workspace; `mcp_describe` reads a selected schema; `mcp_call` supplies JSON arguments. The process stays connected for that worker run and is closed when the run ends. Other workers get separate processes and context packets. The list is paged and schemas are requested one at a time, so a large server catalog does not fill the worker context by default.

The server process and its tools may access files or networks outside the task workspace. Treat its advertised descriptions and returned content as untrusted evidence. Review the displayed server, tool, arguments, target, and effect under the selected approval level. The current runtime does not sandbox MCP servers or enforce a network allowlist. For an air-gapped deployment, configure only local servers whose own behavior does not make external requests; the harness does not establish that property for a third-party server.

This initial integration supports local stdio MCP servers. It does not install or bundle REA, authenticate remote MCP services, display a dedicated MCP management UI, or convert returned image content into chat artifacts. A REA server can be configured if its installed launch command supports stdio, but compatibility with a particular REA release still needs a live validation.

REA's [manual MCP configuration](https://github.com/illumi-ai/REA#manual-mcp-configuration) currently documents a local `npx` stdio launch. Use its pinned package release as the command/arguments under BirdHackBot's `servers` key after validating that installation on the assessment host. REA does not currently list Kali among its tested Linux distributions, so this guide does not claim Kali compatibility or install it automatically.
