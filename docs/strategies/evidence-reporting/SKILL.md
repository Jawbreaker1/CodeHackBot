# Evidence synthesis and reporting

1. Reconcile each worker's assigned goal, actual method, outcome, and evidence references. A completed tool call is not the same as a proven finding or completed assessment goal.
2. Group duplicate observations by root cause and affected boundary. Separate reproduced findings, plausible candidates, negative tests with stated coverage, and unresolved gaps.
3. For each finding, preserve exact scope, prerequisites, reproduction steps, observed result, impact, evidence path, and actionable remediation. Avoid unnecessary secrets or private data in operator-facing text.
4. Prioritize by demonstrated impact and exposure, while making confidence and assumptions visible. Do not inflate severity from an unvalidated CVE match or tool label.
5. Write a readable executive view and a technical evidence trail. Check that every cited artifact exists and supports the specific claim before finalizing.
