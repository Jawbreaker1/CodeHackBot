# Blind client-flow comparison

This local evaluation checks whether BirdHackBot follows a sensitive value from a browser URL to an outgoing request, rather than merely listing endpoints. The two fictional Harbor Booking builds live in `testdata/client-flow-lab/build-a/` and `build-b/`. Each has a small page shell and one script. The operator prompt names both directories but does not disclose which build has the problematic ordering. The review is source-only: no page scripts, external requests, or target modifications are authorized.

The control difference is deliberately small. Both scripts read an `invite` query value, redeem it through a same-origin POST, and construct telemetry containing the current page URL. Build A calls telemetry before removing the query string. Build B removes a nonempty invitation from the visible URL before telemetry. A separate Node run with stubbed browser APIs and no network confirmed that the synthetic marker enters Build A's attempted telemetry URL and is absent from Build B's. That check establishes fixture behavior, not deployed exploitability.

The GUI assessment is `sessions/web/client-flow-eval-20261004/web-assessment-20261004-120656.328081718-000002/`, using `gpt-daybreak-blue-latest` and two parallel workers. Both workers traced the relevant source paths. Build A's worker identified the invitation-to-telemetry path and correctly called it source-confirmed but runtime-unverified. Build B's worker identified the earlier cleanup and distinguished it from a separate residual risk: other URL values can still reach telemetry. The coordinator correctly compared the builds, reported Build A's path as a candidate rather than a reproduced finding, and retained the runtime limitations. It also identified the common query-string design and Build B's residual full-URL telemetry as separate candidates. The final GUI run completed in 595 seconds with 16 model calls, two worker tasks, and two coordinator plans.

This is a positive detection result on a tiny, unlike local fixture, not proof of reliable discovery in a deployed application. One coordinator response was rejected because it tried to close a lead that had never been opened; the correction succeeded but added latency. Most of the ten minutes went to model turns, repeated file handling, and evidence preparation for about sixty lines of code. A larger deployed bundle may still be missed if a broad worker assignment allows inventory to displace a focused path trace.
